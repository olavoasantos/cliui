Add CSS transitions and animations

CSS transitions with `transition-property`, `transition-duration`, `transition-timing-function`, and `transition-delay`. `@keyframes` animations with `animation-name`, `animation-duration`, `animation-timing-function`, `animation-delay`, `animation-iteration-count`, `animation-direction`, and `animation-fill-mode`. Easing functions: `linear`, `ease`, `ease-in`, `ease-out`, `ease-in-out`, `cubic-bezier()`, and `steps()`. Value interpolation for colors, lengths, and numeric properties. Animation tick integrated into the terminal render loop.
