Add Input and Textarea components

`<input>` with single-line editing, readline keybindings (Ctrl+A/E/K/U/W), word/line deletion, mouse focus, and Esc blur. `<textarea>` with multi-line editing, virtual scroll viewport, Shift+Enter for newlines, placeholder text, and vertical cursor navigation. Both support text selection via Shift+Arrow and clipboard operations.
