Add terminal I/O with keyboard, mouse, and focus

Terminal mode lifecycle management (alt screen, raw mode, mouse tracking). Keyboard input parsing for printable characters, control sequences, arrow keys, and modifiers. Mouse event parsing for click, wheel, and movement. DOM event dispatch for keydown, keypress, mousedown, mouseup, click, wheel, mousemove. Tab-based focus cycling with focus/blur events. Terminal resize handling via SIGWINCH.
