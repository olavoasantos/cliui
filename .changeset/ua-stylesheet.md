Add user-agent stylesheet for semantic HTML elements (COMP-1). Block elements (h1–h6, p, blockquote, etc.), inline elements (span, a, strong, em, etc.), and text styling defaults (bold, italic, underline, link color) now render with sensible terminal defaults. User stylesheets and inline styles override UA rules at any specificity.
